# ギフト積み上げ

## 使い方

1. アプリを再起動し、エフェクトカタログの「ギフト積み上げ」を開きます。
2. 出力先のOverlayを選びます。縦配信の場合はOBSのブラウザソースを1080×1920に設定してください。
3. エフェクトプリセットにスロットを追加し、「ギフト積み上げ」を選択して保存します。初期トリガーはすべてのギフトです。
4. カタログの「Test」で共通のプレゼント画像が1個落ちます。実際のギフト受信時は、そのギフトの画像を使います。

カタログの設定だけでは受信トリガーは有効になりません。既存アプリと同様にプリセットへの追加・保存が必要です。

## 動作

- ギフト1個につき物体1個。連続ギフトの累計通知は差分を取り、10個のギフトから合計10個を生成します。コイン数は生成個数に使いません。
- 初期サイズは44px、保持上限は1,000個。カタログ詳細とプリセットで変更できます。
- 画面上部のランダムな位置から落下し、床・側面・ほかのギフトに当たって軽く跳ね、積み上がります。
- 上限に達すると、新しい物体の生成時に古いものから削除します。画面サイズに対して物体が大きい場合は、画面に入る個数を目安に保持数を減らします。
- 大量受信は毎秒最大60個を順次生成します。待機中の個数も全消去の対象です。
- 各物体の初期寿命は15分。新しいギフトを受信すると、その時点で残り寿命が15分以下の生存物体に15分を加算します。
  - 残り10分なら25分になります。
  - 残り20分なら延長しません。
- 寿命が尽きた物体は約1.2秒でフェードアウトします。寿命が尽きた物体は次のギフトで復活しません。
- 画像が未取得・読み込み失敗の場合は同梱のプレゼント画像を表示します。
- 「蓄積ギフトを全消去」は指定Overlayの蓄積と落下待ちだけを消します。
- 蓄積はブラウザのメモリだけに保持します。OBSブラウザソースの再読み込みで空になります。通信の再接続だけでは消しません。未接続中のギフトは再送しません。

## 検証

個数・累計差分・寿命・上限・1,000個の積み上げ・プリセット保存からWebSocket送信・Overlayを限定した全消去を自動テストしています。実際のOBS上の描画と配信サービスの実ギフトについては別途確認が必要です。
